# Elevator + controller simulator
User objective: combine the existing B5–10F Blender elevator with a controller model and a working app that behaves like a conventional passenger elevator.
Delivery: private browser app, local source package, integrated Blender model and separate controller model. Existing files remain intact.
Model: export the actual existing cabin/doors/landings/shaft to GLB, add a physical controller cabinet with logic board, drive, contactors, terminal blocks and status lamps. App uses the actual exported geometry.
Controller: 15 stops at 3.5 m pitch, starting 1F. Car calls plus directional hall calls. Collective selective dispatch, do not reverse before serving requests ahead. Opposite hall calls wait for matching direction or terminal reversal. Deduplicate requests. Mid-flight intermediate stops only when braking distance permits. 1.75 m/s and 0.8 m/s² assumed motion values.
Door states: closed, opening, open, closing. Only move while closed. Only open while level and stopped. 3 s dwell. Reopen for obstruction; obstruction prevents closing. Cab and aligned landing doors synchronize. Hall doors elsewhere remain shut. SOS is a simulated alarm, not a brake. Separate pause/reset controls.
UI: Korean, dark industrial simulation workspace, large 3D viewport, cabin button panel, building floor strip with directional calls, compact live controller telemetry and event log. View presets cabin/lobby/shaft/controller; drag/zoom orbit; active buttons illuminated. Real-time movement and counterweight. Optional sound, default off; speed multiplier 1/2/4 with explicit display. Mobile stacks controls without horizontal overflow.
No real machinery control, no hardware protocol, no auth/database feature added. Clear simulation-only labeling.
Verification: engine tests cover requests, motion/door invariant, endpoints, duplicate inputs, same floor reopen, obstruction, directional hall dispatch, braking-safe insertion, queue drain, pause/reset. Browser smoke test loads the actual GLB, exercises buttons and view changes; screenshots at desktop and mobile. Private publication if available, otherwise usable local package.
