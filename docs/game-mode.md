# First-person game mode
User intent: walk with WASD, click physical elevator buttons, board and exit at destinations using the existing working controller.
Implementation: keep observer simulation intact; toggle a first-person workspace. A pure WalkingPlayer model handles horizontal walking, collisions, occupied floor, cabin riding and doorway occupancy. A GameMode adapter handles keyboard/mouse, camera and HUD. LiftScene uses the same GLB buttons with bounded-distance, occlusion-aware picking.
Geometry: eye 1.65 m, body radius 0.18 m, walk 2.0 m/s. Walkable 1F lobby starts at x=0,z=2.65; existing cabin at x[-0.7,0.7],z[-0.62,0.66], doorway x[-0.25,0.25],z[0.66,1.40], lobby x[-2.28,2.28],z[1.40,3.42]. Passage requires aligned car and >=95% open doors. Axis-separated substeps prevent tunneling and permit wall sliding. Car occupants keep horizontal coordinates and inherit car height; non-occupants stay at their floor. No jumps, stairs, gravity/falling or teleport shortcuts.
Interaction: WASD (physical key codes), right-drag look, left-click physical buttons. Optional pointer lock with center aim, Escape releases. Direct buttons require <=1.8 m distance and unobstructed line of sight; hall buttons only on occupied landing, car buttons only inside. Pointer-lock denial falls back to right-drag. Blur and mode changes clear held input. On pause movement freezes. Exiting in doorway returns player to their last safe side.
Door sensor: independent named manual/player sources so disabling one cannot clear the other. Occupancy sets source before stepping controller and after movement, only when the car is aligned at the player’s floor. The closed-landing stopping position is outside the sensor region. Leaving game/reset removes only player source. Game fixes simulation playback to 1x.
UI: explicit game toggle, large first-person viewport, current location, interaction prompt and concise controls. Observer panels hidden while playing. Minimal lobby side/back walls and ceiling enclose walkable space. Existing 3D asset, dispatch and safety behavior preserved.
